# lesson-prep-skills

面向中小学教师的备课技能包，可被罗湖教育云 Harness、Claude Code 等支持 Skill 机制的 AI 平台加载。

## 技能列表

| 技能 | 说明 |
|---|---|
| [`lesson-prep-three-align`](skills/lesson-prep-three-align/SKILL.md) | 三对齐·四步闭环备课法：三对齐（课标／教材／学情）＋学科教案模板适配＋「定标·设计·配评·回流」四步闭环 |

## 在罗湖教育云 Harness 中使用

1. 打开 `技能市场` → `网络技能市场`
2. 在「按仓库浏览」填入本仓库的 `GitHub 用户名/仓库名`，分支 `main`
3. 点「拉取技能列表」→ 找到 `lesson-prep-three-align` → 一键存入「我的技能」

也可以直接下载 `skills/lesson-prep-three-align/SKILL.md`，在 `学校技能市场` 右上角上传共享。

## 配套语料

本技能本体不含任何学科专属内容，学科差异全部通过知识库文件承载：

| 语料 | 必需 | 说明 |
|---|---|---|
| 课程标准 | 是 | 对应学科的课标全文 |
| 教材 | 是 | 要备的单元即可，不必传全册 |
| 学科教案模板 | 是 | 格式见 SKILL.md 附录 B 的元信息表头 |
| 学情档案 | 建议 | 模板见 SKILL.md 附录 A |
| 优秀教学设计样例 | 可选 | 3—5 份即可 |

**加一个学科 = 传一份教案模板文件，技能本体不用改。** 这是本技能可跨学科推广的前提。

## 版本

| 版本 | 改动 |
|---|---|
| 1.0.0 | 三对齐 ＋ 四步闭环 |
| 1.1.0 | 新增学科教案模板适配：模板前置加载、全程栏目约束、末端装配、《模板合规自检表》 |
| 1.2.0 | 首次真实课堂试用后修订：模板检索规程（双存储&多模板消歧）、装配须在原件副本上填写、交付物按模板原生格式、来源标注跨轮传递、教师纠偏留痕、单步推进 |

v1.1.0 的改动来自一个实践中发现的问题：AI 生成内容后教师仍需手工重排为区定教案模板，**格式返工成为备课的「最后一公里」隐性成本**，且这部分耗时长期被算在「备课时长」之外，没有单独计量过。

v1.2.0 的改动全部来自**第一次真实课堂试用的 13 轮对话日志**。技能本体的铁律（决策点、留痕、缺料即停）经受住了检验，失效的是执行细节：助手只检索了工作区目录就断言"模板未上传"，而模板一直在知识库里，空转 4 轮；知识库同时存在通用版与学科版模板时选错了通用版；成品连出两轮 Markdown 中间稿；装配阶段用脚本从零重建 Word 版式而非在原件上填空，单轮消耗 26 次模型调用。另有一处更隐蔽的问题：一条标注为"二手来源、需核实"的课标引用，在后续轮次的转述中被升格为"知识库权威来源"——**来源标注会在多轮传递中被洗白**，这对"数据真实可追溯"是实质风险，故新增标注传递规则。
